## 1. Что это за проект

**iBC Shell**: открытый кроссплатформенный SSH + SFTP клиент (Tauri 2 + Rust + SvelteKit/Svelte 5).
Ориентиры по уровню: Termius (функции) и SwiftServer (https://swiftserver.app: мониторинг серверов, оформление в духе Apple).
Владелец пишет по-русски, хочет «премиум, как Apple»: легко, лаконично, светлая тема по умолчанию.

- Репозиторий: `https://github.com/dramaformama/ibc-shell` (origin настроен, **ни разу не пушили: перед первым `git push` спросить владельца**).
- Папка: `/Users/georg/Documents/files/CodeINK/ibc-shell`, ветка `main`.
- Имена: крейты `ibc-shell-*`, пакет `ibc-shell`, идентификатор `app.ibcshell.desktop`, служба связки ключей `app.ibcshell`.

```
crates/store  SQLite, дерево папок/хостов, наследование настроек
crates/vault  шифрование секретов (XChaCha20-Poly1305 + Argon2id), связка ключей ОС, бэкапы
crates/ssh    russh-клиент: подключение, авторизация, ключи хостов, PTY
crates/sftp   SFTP и движок передач (очередь, докачка, конфликты)

ui            SvelteKit (static) + Svelte 5 runes + Tailwind 4 + bits-ui + xterm.js

```

- **Новый интерфейс (несколько раундов по замечаниям владельца):**
  - Одна вкладка = один сервер. «Терминал» и «Файлы» — два вида внутри группы вкладок (`sessions.groups`, `groupKey`, `switchKind` в `ui/src/lib/stores/{sessions.svelte.ts,actions.ts}`).
  - Точка статуса у вкладки: зелёная — подключено, жёлтая мигает — подключается, красная — ошибка.
  - Крестик на вкладке, кнопка питания и ⌘W отключают сервер целиком. ⌘1…9 и Ctrl+Tab переключают серверы.
  - Кнопка боковой панели всегда первая в полосе вкладок (`TabBar.svelte`). Поиск стоит в верхней строке боковой панели рядом с кнопками окна.
  - Дубля «Открытые» в боковой панели нет: владелец явно не хочет повторять вкладки.
  - У хоста в дереве при наведении появляются кнопки «Терминал» и «Файлы» (`TreeRowContent.svelte`, стили в `tree.css`). Зелёная точка — сервер открыт.
  - Форма хоста (`HostEditor.svelte`): «Адрес + порт», «Название» (необязательно), «Флаг», блок «Вход» с переключателем «Пароль / Ключ SSH». Пароль сохраняется как identity типа `password` (создаётся или обновляется автоматически), ключ импортируется через `identity_import_file`. Прочее свёрнуто в «Дополнительно».
  - **Папки без учётных данных** (`FolderEditor.svelte`: только имя и флаг). Хосты раскладываются по папкам только перетаскиванием, выбора папки в форме нет.
  - SFTP: ширина колонок (Размер, Изменён, Права) и разделитель панелей тянутся мышью, двойной клик сбрасывает. Хранится в localStorage `ibc.sftp.layout` (`ui/src/lib/sftp/layout.svelte.ts`).
  - Подсветка вывода терминала в духе Termius (`ui/src/lib/terminal/highlight.ts` + тесты). Красит IP, URL, error/failed/denied, warning, ok/active/done, проценты и размеры. Трогает только текст со стандартным цветом на обычном экране, не трогает vim/top. Переключатель в Настройках, ключ `term.highlight`.
  - Оформление в стиле Apple (`ui/src/app.css`): системная палитра (`#f2f2f7` и белые карточки, тёмная тема `#1c1c1e`), кнопки-капсулы, круглые иконки-кнопки, класс `.card`, цвета разделов `--c-cyan/yellow/pink/purple/green/orange`, плавающая скруглённая панель редактирования (`Sheet.svelte`), **выбор акцентного цвета** (9 системных цветов Apple, `settings.accent`, атрибут `data-accent` на `<html>`, применяется до первой отрисовки в `app.html`).
  - Найденный и исправленный баг: терминал был `position:absolute` без относительного родителя и закрывал всё окно. Теперь у `.stage` и `.content` стоит `position: relative`.

## 4. Незавершённое (продолжать отсюда)

### 4.1 Метрики сервера в стиле SwiftServer (главная текущая задача)
Цель владельца: «забрать суть SwiftServer и оформить под Apple».
Нужны три вещи:
1. Живые CPU, нагрузка, память, диск, сеть и процессы **колонкой рядом с терминалом** (инспектор).
2. Главный экран **«Сводка»** с карточками подключённых серверов: кольца CPU и RAM, сеть ↑↓, ядра, RAM, диск, аптайм.
3. Цветные карточки разделов.

**Обновление Codex, 2026-11-07:** бэкенд и `wip/stats-ui` уже были слиты в `main` до начала продолжения (HEAD `155b01d`); дополнительных worktree нет.

Интеграция завершена:
- В `+page.svelte` терминалы остаются смонтированными в относительной `.content`, справа показывается `Inspector`, только для активного терминала.
- В боковой панели постоянная «Сводка»; при скрытой панели её кнопка доступна в `TabBar.svelte`; кнопка инспектора рядом с «Терминал / Файлы». Видимость хранится в `ibc.ui.inspectorOpen`.
- `stats/Dashboard.svelte`: карточки открытых серверов, счётчики «Всего / В сети / Не в сети», возврат к серверу по клику. Без серверов — приветственный экран.
- Реальные bindings допускают `null` для float-метрик: UI показывает «—», графики сохраняют разрывы. `Unsupported` прекращает опрос до повторного открытия вида.
- Опрос общий для наблюдателей; переключение инспектор ↔ сводка не запускает параллельных циклов. Регрессионные тесты в `stats.svelte.test.ts`.
- Обновлены README на обоих языках и ручные проверки метрик в TESTING.

Проверено: `cargo clippy --workspace --all-targets -- -D warnings`, `IBC_BIG_MIB=8 cargo test --workspace`, `cargo deny check`, UI check / test (75 тестов) / lint / build. Для SSH mock_server понадобился запуск вне sandbox (локальный TCP bind); Docker SSH e2e остаются штатно ignored без `TL_E2E=1`. Скриншоты мок-интерфейса: `/private/tmp/ibc-stats-{inspector,overview}-{light,dark}.png`; проверены переходы сводка ↔ терминал ↔ файлы и сохранение переключателя. CLI `impeccable` в окружении отсутствует, `detect` не запускался. Итоговые скриншоты нового UI на русском в `docs/brand/screenshots/overview-{light,dark}.png`, встроены в README. Браузерные сценарии прошли: поиск/фильтры, три живых подключения, сохранение папки SFTP, редактор хоста, ru/en, обе темы, узкое окно; отдельно проверена прокрутка 5000 карточек с <30 смонтированными элементами.

**Следующий раунд Codex по запросу владельца о стиле и архитектуре SwiftServer:**
- Принят ADR-010, UI/IPC v1.1. Разбор первичных источников — `docs/swiftserver-reference.md`; закрытое устройство SwiftServer не выдаётся за известный факт.
- Главная теперь опирается на **каталог сохранённых серверов**, а не вкладки: `ui/src/lib/fleet/model.ts` объединяет inventory, SSH-состояния и наблюдения доступности; `fleet.svelte.ts` — проекция для UI.
- `host_probe` в Rust: TCP-подключение к разрешённому SSH-порту (таймаут 3 с, ≤4 одновременно), без логина и доверия ключам. Команда пассивная, требует unlocked vault; для jump-host маршрутов возвращает Unsupported. Это доступность порта, не здоровье ОС/успешный вход и не ICMP RTT. Нет новых зависимостей: включена feature net существующего tokio.
- `reachability.svelte.ts`: общие наблюдатели, очередь, период 30 с, прекращение новых проверок при скрытии и очистка при lock. Состояния Unknown / Online / Offline отдельно от Connecting / Connected / Failed. Проба старше 60 с не считается свежей.
- Сводка: поиск имени/адреса/папки, счётчики-фильтры, виртуализированная сетка (проверка 5000 хостов), карточки с отдельными Terminal/Files/Edit; актуальные метрики подключённых Linux-серверов, без выдуманных данных для остальных.
- Общие элементы: `controls.css`, `forms.css`, токены `app.css`. Согласованы кнопки/поля/сегменты/select/switch, toolbar 52 px, sidebar Overview, группированные формы/настройки, карточки и инспектор. CSS файловой панели разделён по ответственности, каждый изменённый UI-файл ≤400 строк.
- `SftpHost.svelte` сохраняет файловые виды при переключении. Если терминал уже подключён, SFTP берёт его session_id вместо нового логина. При открытии Files раньше терминала самостоятельный транспорт сохраняется.
- `stats` хранит timestamp/stale; ошибка обновления не превращает старый sample в нули. Отсутствующие значения — «—» без фиктивного процента.

Следующий шаг: приёмка на настоящем Linux-сервере (пробы сети, общий SSH для Terminal→Files, обрыв, отсутствие влияния опросов на автоблокировку). Отдельного exec-only мониторинга без терминальной сессии пока нет: вход запускается явно кнопкой подключения; автоматического входа во все сохранённые серверы нет. Референс SwiftServer включает независимые monitoring sessions — это дальнейшее развитие, не скрытая готовая возможность.

- Дальше в духе SwiftServer (по желанию владельца, по одному): панель Docker (контейнеры: статус, образ, порты, CPU/RAM; через `docker ps`/`docker stats --no-stream` exec), карта мира с задержкой до серверов, пинг (RTT) в карточке, сниппеты, проброс портов (Фаза 3), Touch ID перед показом паролей.

### 4.2 Известные проблемы
- SFTP теперь переиспользует соединение уже подключённого терминала и сохраняется при навигации. Если Files открыт первым — соединение самостоятельное. При обрыве родительского SSH проверить поведение SFTP/передач вживую.
- Старые хосты могут брать логин из настроек папки (наследование осталось в данных), а новая форма папки их больше не показывает. Нужно либо убрать наследование учётных данных, либо показать его.
- Открытые находки безопасности #6–#9 и #11–#14 в `docs/security-review.md`. Сначала #6 (нет защиты навигации и новых окон) и #12 (`core:event:default` слишком широкий; нужны `allow-listen` и `allow-unlisten`).
- Ручная приёмка G2 (`docs/TESTING.md`) владелец начал: хранилище создаётся, подключение и терминал работают на реальном сервере Ubuntu. SFTP, обрыв и докачка, автоблокировка вживую не пройдены.
- `FlagPicker` не виртуализирован (~270 строк). paraglide при сборке может тянуть плагин с CDN.
- Нет файла LICENSE (спросить владельца, как подписать). Скриншоты сводки в README добавлены. Social preview для GitHub лежит в `docs/brand/`, загружается вручную после первого пуша.
- Select в SFTP оформлены в общем стиле; состояние каталогов сохраняется при навигации.
