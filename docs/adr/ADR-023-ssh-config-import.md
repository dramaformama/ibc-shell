# ADR-023. Импорт из `~/.ssh/config`

Статус: принято.

Программа читает `~/.ssh/config` пользователя и показывает его хосты до импорта. Путь не приходит из интерфейса: backend сам берёт файл в домашней папке, а для `Include` открывает только файлы, которые указал сам конфиг. Файлы больше 1 МиБ, ключи больше 64 КиБ и больше 64 файлов на один `Include` пропускаются. Вложенность `Include` не глубже 8.

Разбор следует `ssh_config(5)`: первое значение побеждает, шаблоны `Host` с `*`, `?` и `!` применяются к конкретным именам, блоки `Match` пропускаются. Импортируются `HostName` (с `%h`), `User`, `Port`, `IdentityFile`, `ProxyJump`, `LocalForward`, `RemoteForward` и `DynamicForward`. `ProxyCommand` не поддерживается, предпросмотр об этом говорит.

`ssh_config_preview` возвращает хосты, состояние ключа (есть, с парольной фразой, не найден, не распознан) и отметку, что такой хост уже сохранён. `ssh_config_import(aliases, folder_name)` перечитывает файл сам, а интерфейс только выбирает имена. Хосты попадают в новую папку. Ключ без парольной фразы сохраняется в хранилище один раз, уже сохранённый ключ с тем же отпечатком используется повторно. Ключи с парольной фразой не импортируются: хост создаётся без ключа и может войти через ssh-agent. Хост из `ProxyJump`, которого нет среди импортируемых и сохранённых, создаётся в той же папке. Цикл или цепочку длиннее трёх прыжков хранилище отклоняет, тогда хост остаётся без прыжка. Содержимое ключей никогда не уходит в интерфейс.
