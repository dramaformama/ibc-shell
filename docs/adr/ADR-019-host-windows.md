# ADR-019 — Отдельные окна хостов

- Статус: принят
- Дата: 2026-11-14

Главное окно открывает отдельное окно через `host_window_open`. Rust принимает ID сохранённого хоста и начальный режим, сам создаёт метку и внутренний URL. Новое окно использует оформление главного и те же ограничения навигации. Если хост уже открыт, перетаскивание вкладки и её контекстное меню передают существующие SSH/SFTP-сессии. Пункт меню сайдбара открывает отдельное окно для сохранённого хоста.

Вывод терминала при передаче буферизуется с прежним SSH backpressure. Снимок xterm, пути панелей и вид инспектора передаются в памяти. Исходное окно убирает вкладку после подтверждения. При отмене выводу возвращается прежний получатель.

Терминалы, SFTP и подписка на передачи привязаны к окну для очистки при его закрытии. События общей очереди передач доставляются каждому подписанному окну.
