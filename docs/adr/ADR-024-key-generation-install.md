# ADR-024. Создание ключей и установка на сервер

Статус: принято.

`identity_generate(label, algo)` создаёт ключ Ed25519 (по умолчанию) или RSA 4096 через системный генератор случайных чисел. Закрытая часть сразу уходит в хранилище, интерфейс получает только `IdentityDto` с открытым ключом и отпечатком.

`identity_install(session_id, identity_id)` работает как `ssh-copy-id`: через уже открытое соединение сессии выполняет короткий скрипт `sh`. Скрипт создаёт `~/.ssh` (права 700) и `authorized_keys` (600), если их нет. Если ключ уже есть в файле, он ничего не меняет, иначе дописывает строку `<алгоритм> <ключ> ibc-shell` с переводом строки перед ней при необходимости. В команду попадают только алгоритм и base64 ключа после проверки символов (`[A-Za-z0-9+/=@.-]`), поэтому подставить в неё что-то постороннее нельзя. Комментарий ключа из хранилища в команду не попадает.

Интерфейс на странице сервера предлагает «Входить по ключу»: создать или выбрать ключ, установить его и переключить хост на этот ключ. Хост переключается, только если установка прошла. Прежняя учётная запись с паролем не удаляется. Серверы Windows с `administrators_authorized_keys` этим способом не поддерживаются: скрипт сообщит об ошибке.
