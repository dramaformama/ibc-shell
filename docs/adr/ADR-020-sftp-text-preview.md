# ADR-020. Встроенный просмотр файлов SFTP

Статус: принято.

Двойной щелчок, Enter, пробел и пункт «Просмотреть» открывают окно просмотра выбранного файла. Системное открытие по ADR-018 и копирование во вторую панель доступны в том же окне.

Команда `file_preview` читает начало или конец обычного файла порциями по 5 МиБ, до 20 МиБ в одном превью. Для сервера используется действующая SFTP-сессия. Для локальной панели действуют разрешённые корни. Символические ссылки разрешаются до проверки типа файла. Данные читаются по запросу пользователя, не сохраняются и отображаются как обычный текст. Превью поддерживает UTF-8, включая BOM, и отклоняет двоичные данные и неизвестные кодировки. При неполном чтении интерфейс показывает, какая часть файла отображается.
