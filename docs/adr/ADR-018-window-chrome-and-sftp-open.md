# ADR-018 — Оформление окна и открытие файлов SFTP

- Статус: принят
- Дата: 2026-11-14

Заголовок главного окна встроен в панель приложения. macOS использует Overlay и системные кнопки. Windows и Linux используют окно без системного заголовка и кнопки в панели. Права Tauri ограничены главным окном и операциями перетаскивания, сворачивания, разворачивания и закрытия.

«Открыть» для файла показывает диалог с отдельными действиями открытия в системном приложении и копирования во вторую панель. Команда `file_open` принимает существующий `Endpoint` и путь. Для локальных файлов действуют разрешённые корни, для удалённых — открытая SFTP-сессия. Открытие доступно для обычных файлов распространённых документных и медиаформатов. Символические ссылки разрешаются до проверки типа и пути. Размер удалённой копии ограничен 256 МиБ. Копия хранится в отдельном временном каталоге приложения до его закрытия. Изменения в ней не отправляются на сервер. Для остальных файлов доступна очередь передач.

Содержимое и путь временной копии остаются в Rust. Системное приложение запускается через системный обработчик файлов. На Windows используется ShellExecute через библиотеку `open`. `tempfile` создаёт изолированные каталоги и удаляет их при штатном выходе.
