# ADR-027 — Отрыв вкладки с «призраком» и возврат из отдельного окна

- Статус: принят
- Дата: 2026-11-16

Дополняет ADR-019.

**Призрак вкладки.** Пока вкладку тянут вниз из панели вкладок, она отрывается: в панели остаётся пустое место, а за курсором летит карточка вкладки. Внутри окна карточку рисует страница. Веб-страница не умеет рисовать за краем окна, поэтому за его пределами показывается крошечное окно `tab-ghost`: без рамки, без фокуса, поверх остальных, пропускает клики (`tab_ghost_open` / `tab_ghost_move` / `tab_ghost_close`). Его страница `tab-ghost.html` статическая, получает только имя, код флага (проверяется по `[a-z-]{2,12}`) и тему. Прозрачность окон на macOS требует приватного API, поэтому призрак прямоугольный и непрозрачный. В браузерном превью призрак есть только внутри страницы.

**Возврат.** Отдельное окно отдаёт сессии обратно главному через `host_window_return`: та же проверка владельца, что у `host_window_open`, запись передачи с меткой `return-*` и событие `host-window://return` только окну `main`. Главное окно забирает сессии через `host_window_adopt`, открывает вкладку (если хост уже открыт — как ещё одно подключение) и восстанавливает экран терминала и пути панелей. Отдельное окно ждёт подтверждения через `host_window_transferred` и закрывается само. Вернуть можно пунктом меню вкладки или перетащив вкладку на главное окно.
