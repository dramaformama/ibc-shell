# ADR-022. Проброс портов

Статус: принято.

Правила проброса хранятся у хоста (`port_forward`). Запускаются они в открытой терминальной сессии этого хоста, потому что пользуются её SSH-соединением.

Команды: `forward_start(session_id, forward_id)` возвращает занятый порт, `forward_stop`, `forward_active`. Каждое изменение состояния приходит событием `ForwardStatus` в канал сессии. Правила с `auto_start` запускаются сразу после подключения. Когда соединение закрывается, все пробросы сессии останавливаются. Удаление правила сначала останавливает его во всех сессиях. Изменённое правило продолжает работать со старыми настройками, пока его не перезапустят.

Виды:
- локальный (`-L`): порт на этом компьютере, каждое подключение идёт каналом `direct-tcpip` к назначению со стороны сервера;
- обратный (`-R`): запрос `tcpip-forward`, сервер открывает каналы `forwarded-tcpip`, приложение соединяет их с назначением на этом компьютере. Каналы для портов, которые не запрашивались, отклоняются;
- SOCKS5 (`-D`): только CONNECT без аутентификации, адреса IPv4, IPv6 и доменные имена.

По умолчанию адрес 127.0.0.1. Другой адрес можно указать, интерфейс предупреждает, что порт станет доступен в сети. На один проброс приходится не больше 256 одновременных подключений, лишние сразу закрываются. Клиенту SOCKS и локальному назначению обратного проброса даётся 10 секунд на установку соединения.
