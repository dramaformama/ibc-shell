# ADR-021. Показ сохранённого пароля хоста

Статус: принято.

Пользователь забывает пароли, которые сохранил в программе, и хочет видеть их в карточке хоста. Данные хранятся только локально, в хранилище на этом устройстве.

Команда `identity_reveal_password(id)` возвращает сохранённый пароль учётной записи или `null`, если пароля нет. Интерфейс вызывает её только по нажатию кнопки с глазом в редакторе хоста, а не при открытии карточки. Хранилище должно быть открыто. Пароль не пишется в журналы и ошибки. Если пароль не изменили, он не перезаписывается в хранилище.

Это исключение из правила «секреты не возвращаются в JS». Закрытые ключи и фразы-пароли к ключам по-прежнему не возвращаются.
